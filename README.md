# Lark Calendar - 飞书日历

一个现代化的日历应用，类似于飞书日历的功能和界面设计。

## 功能特性

### 📅 多视图模式
- **月视图**: 完整的月份概览，显示所有日程
- **周视图**: 详细的周视图，按小时显示时间槽
- **日视图**: 单日详细视图，完整的时间线
- **议程视图**: 列表形式显示即将到来的日程

### 📝 日程管理
- **创建日程**: 支持标题、描述、时间、地点、参与者
- **编辑日程**: 完整的编辑功能，支持所有字段修改
- **删除日程**: 安全的删除确认机制
- **全天事件**: 支持全天事件和定时事件
- **颜色标签**: 10种预设颜色，便于分类管理

### 🔔 提醒功能
- **多种提醒时间**: 支持事件开始时、5分钟前、15分钟前、30分钟前、1小时前、1天前
- **浏览器通知**: 基于Web Notifications API的桌面通知
- **自动提醒**: 后台自动检查并发送提醒

### 📱 响应式设计
- **移动端优化**: 完全适配手机和平板设备
- **触摸友好**: 优化的触摸交互体验
- **自适应布局**: 根据屏幕尺寸自动调整界面

### 🎨 现代化UI
- **简洁设计**: 清爽的界面设计，符合现代审美
- **流畅动画**: 平滑的过渡动画和交互反馈
- **无障碍支持**: 良好的键盘导航和屏幕阅读器支持

## 技术栈

- **前端框架**: React 18 + TypeScript
- **状态管理**: Zustand
- **样式方案**: Tailwind CSS
- **UI组件**: Radix UI
- **日期处理**: date-fns
- **表单处理**: React Hook Form + Zod
- **构建工具**: Vite
- **图标**: Lucide React

## 使用说明

### 创建日程
1. 点击右上角的"新建日程"按钮
2. 填写日程信息（标题为必填项）
3. 选择开始和结束时间
4. 可选择是否为全天事件
5. 设置提醒时间
6. 选择颜色标签
7. 点击"创建"保存

### 查看和编辑日程
- 在日历视图中点击任意日程可查看详情
- 在详情弹窗中点击"编辑"按钮可修改日程
- 支持删除不需要的日程

### 切换视图
- 使用顶部的视图切换按钮在月、周、日、议程视图间切换
- 使用左右箭头导航到不同的时间段
- 点击"今天"按钮快速回到当前日期

### 通知设置
- 首次使用时浏览器会请求通知权限
- 允许通知后，系统会在设定的时间发送提醒
- 支持多个提醒时间点

## 开发说明

### 添加新功能
1. 在 `types/index.ts` 中定义相关类型
2. 在 `store/calendar.ts` 中添加状态和操作
3. 创建对应的组件文件
4. 在主应用中集成新功能

### 样式定制
- 修改 `tailwind.config.js` 自定义主题色彩
- 在 `src/index.css` 中调整CSS变量
- 使用 `cn()` 工具函数合并样式类

### 数据持久化
当前版本使用内存存储，可以通过以下方式添加持久化：
- localStorage 本地存储
- IndexedDB 客户端数据库
- 后端API集成
